# kanbanniang

## Volo 内置版本

Volo 发行包包含脚本、样式、26 套模型及换装贴图，运行时从本站加载。后台可选择模型；未启用插件时不加载模型。资源清单与来源记录在同目录的 `SOURCES.json` 中。

自定义资源时应保留模型引用的目录结构，并遵守模型原作者的授权。下面的 MIT 协议说明适用于上游插件代码，不代表所有模型和贴图都使用 MIT 协议。

## 简介

[kanbanniang](https://github.com/b3log/kanbanniang) 收集并整理了多款 Live2D 模型。
